# Global University Website 🎓

A multi-page frontend web application built to simulate a comprehensive university portal. I developed this project in 2024 to strengthen my foundational skills in HTML, CSS, and web page routing. 

The website features a clean UI/UX, structured layout, and functional navigation across multiple interconnected pages.

### 🚀 Live Preview
https://kalpit7786.github.io/University-website/
### 🛠️ Tech Stack
* **HTML5:** Semantic structuring and multi-page routing.
* **CSS3:** Custom styling, layouts, and responsive design elements.
* **Libraries:** Font Awesome (for UI icons) and Google Analytics integration.

### 📂 Key Features & Pages
The project is divided into five main interconnected pages:
* **Home (`index.html`):** The landing page featuring a hero section, course overview, global campus locations, and student testimonials.
* **About (`about.html`):** Detailed information about the university's history and mission.
* **Courses (`course.html`):** A breakdown of offered degrees (B.Tech, BCA, MBA, etc.) and campus facilities.
* **Blog (`blog.html`):** A section dedicated to university news, online programs, and post categories.
* **Contact (`contact.html`):** A functional UI contact form and an integrated live Google Maps `iframe` displaying the campus location.
